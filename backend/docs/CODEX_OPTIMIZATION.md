  ใน code block เฉพาะเมื่อจำเป็นจริง
- **ส่งแต่โค้ด:** คำตอบต้องมีเฉพาะโค้ดที่พร้อมใช้งานจริง โครงสร้าง JSON ที่ต้องใช้
  และคำสั่ง Git
